# Тестовое задание SnapJoy Games — Unity Developer

## Архитектура

- **DI** — VContainer управляет зависимостями (`PlayerState`, `InteractionService`, `ItemHolder`, `QuestManager`).
- **Mediator** — UniMediator разделяет UI и логику через запросы/уведомления.
- **ScriptableObject конфиги** — все параметры (скорость, чувствительность, скорости вентиля) в `PlayerConfig` и `InteractionConfig`.
- **Интерфейсы взаимодействия** — `IInteractable`, `IHoldInteractable`, `IPickable` позволяют единообразно обрабатывать разные объекты.

## Реализованные механики

- **Передвижение** от первого лица с блокировкой ввода в режимах инспекции и диалога.
- **Взаимодействие через E** — рейкаст, подсказки, различие нажатия/удержания.
- **Подбор предметов** — осмотр (вращение зажатием ЛКМ), перенос в руку, возврат в гнездо.
- **Записка** — при осмотре раскрывается как книга.
- **Диалоги** — нелинейный с выбором ответов и линейный квестовый (запрос случайного предмета).
- **Квесты** — отображение в UI, завершение при доставке предмета.
- **Вентиль + дверь** — удержание вращает вентиль и поднимает дверь; отпускание — плавный возврат.
- **Сундук с ключом** — открывается только при наличии ключа в руке, ключ тратится.
- **Выключатель света** — дополнительное взаимодействие по `E`.

```
├── Items/ # Предметы, ItemHolder, ItemSocket
├── Dialogues/ # Данные диалогов, обработчик

```
